## 🎯 Текущий статус

### ✅ Что работает
- Калькулятор с 6 операциями (+, -, *, /, **, %)
- История вычислений с сохранением в SQLite
- Темная/светлая тема
- Анимации через Framer Motion
- Toast-уведомления через Sonner + custom hook
- Адаптивный дизайн

### ⚠️ Известные проблемы
- Нет научных функций (sin, cos, log)
- Нет PWA поддержки
- history-panel.tsx не используется (логика в page.tsx)
- calculator-display.tsx не используется (логика в page.tsx)

## 🚀 Как запустить проект

```bash
# Клонировать
git clone https://github.com/pikov-vitaliy/python-calculator.git
cd python-calculator

# Установить зависимости
npm install

# Настроить базу данных
cp .env.example .env
npx prisma db push
npx prisma generate

# Запустить
npm run dev
# Открыть: http://localhost:3000
```
